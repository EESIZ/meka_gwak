# 출처 관리

이 폴더는 연구·유지보수용 출처 기록이다. 실행 지침은 SKILL.md와 references에 두고, 예문·참고값은 data에 둔다.

provenance.json에는 예문 키와 원 판례 사건번호·일자·공식 출처 주소·선택 구간을 연결했다. 예문은 기존 원문에서 추출했으며 검색용 유형 표시는 과거 분석자의 분류다. 실제 판단 맥락은 원문에서 확인한다.

문체 참고값은 보존된 판결 이유를 같은 분석기로 재계산한 기술통계다. 문서별 빈도와 문장 특성을 집계하고, 분야별 법률문서 집단을 공통 참고값으로 사용한다. 문서 종류 사이에 형태소 특성과 논리 전개가 공통된다는 운용상 가정에 따른 것이며, 종결어미는 측정 대상에서 제외되어 있다. 작은 집단은 예문 중심으로 제공한다. 분포의 위치는 퇴고 참고값으로 사용한다.

원문 집단은 작성 방법 개발에 사용한 자료다. 효과 검증은 별도 사건과 일반 AI 대조군으로 수행한다. 책·논문의 전문과 개선 권고는 이 배포 데이터의 범위를 벗어난 별도 연구 자료로 관리한다.
