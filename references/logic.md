# 전개 방식

확인한 판례 법리를 전제로 쟁점에 맞는 흐름을 선택한다. 각 방식의 실제 적용 범위는 해당 판례 원문에서 확인한다.

| 키 | 상황과 방식 | 전개 |
|---|---|---|
| P01 | 요건별 포섭: 규범의 의미보다 사안의 요건 충족이 쟁점일 때 | 적용 요건 제시 → 관련 사실 확인 → 사실과 각 요건의 대응 → 충족 여부와 결론 |
| P03 | 문언·체계·취지를 통한 해석 도출: 판례가 채택한 해석과 적용 범위를 설명할 때 | 판례의 해석 대상 확인 → 판례가 채택한 해석 근거 → 확인된 해석 범위 → 사안 적용 |
| P04 | 유추에 의한 법리 확장: 판례가 채택한 유추의 근거와 범위를 설명하고 적용할 때 | 기존 판례의 대상과 법리 확인 → 판례가 인정한 공통점과 확장 근거 → 확인된 적용 범위 대조 → 사안 적용 |
| P06 | 원칙과 예외의 분기: 기본 규칙과 그 결론을 바꾸는 예외 조건이 존재할 때 | 원칙 제시 → 예외를 허용하는 조건 특정 → 예외 관련 사정 검토 → 원칙 유지 또는 예외 적용 |
| P07 | 이익의 비교·형량: 적용 법리가 구체적인 상충 이익의 비교를 요구할 때 | 충돌하는 이익 특정 → 각 이익의 구체적 내용·정도 확인 → 비교의 근거 제시 → 우열과 결론 |
| P08 | 간접사실의 종합 추론: 간접사실에서 직접 확인하기 어려운 사실을 추론할 때 | 직접 확인하기 어려운 사실 특정 → 관련 간접사실 확인 → 경험칙에 따른 연결 → 인식·의도 등 추론 |
| P09 | 증명책임과 증명 상태의 판단: 요증사실의 증명책임 또는 증명 상태가 결론에 영향을 줄 때 | 증명이 필요한 사실 특정 → 증명책임자 확정 → 주장·증거 확인 → 증명 상태와 추가 심리 필요 판단 |
| P13 | 가정적 양보에 의한 반박: 상대방 전제를 가정해도 주장한 결론이 나오지 않음을 보일 때 | 상대방 전제를 일단 가정 → 그 전제에서 나오는 효과 검토 → 별도 요건·사정 제시 → 주장한 결론의 도출 차단 |
| P02 | 법적 성질 확정과 적용규범 선택: 외형이 유사한 법적 범주에 따라 적용규범이 달라질 때 | 외형이 비슷한 법적 범주 구별 → 목적·내용·효과 확인 → 사안의 범주 확정 → 해당 규범 선택 |
| P05 | 규범 위계와 권한 근거 심사: 하위규범의 효력 또는 행위 권한의 근거가 쟁점일 때 | 상위규범이 요구하는 근거 확인 → 하위규범의 위임·내용 심사 → 효력 판단 → 그에 기초한 처분 판단 |
| P10 | 보호목적을 통한 인과관계·책임 귀속: 의무 위반 후 발생한 손해를 법적으로 귀속시킬 수 있는지 따질 때 | 의무 위반과 손해 구별 → 규정의 보호대상·이익 확인 → 손해가 보호범위에 드는지 판단 → 책임 귀속 |
| P11 | 시점 구분과 적용법 결정: 시점 차이가 적용법이나 소급효 판단을 바꿀 때 | 사실·권리·법령의 시간관계 정리 → 완성된 관계와 계속되는 관계 구별 → 적용법 결정 → 소급·신뢰보호 검토 |
| P12 | 법적 효과의 단계별 분리: 선행 판단에서 별도의 후속 법적 효과를 도출하려 할 때 | 선행 판단 인정 → 후속 법적 효과의 별도 요건 확인 → 추가 요건 심사 → 효과별 결론 구별 |
| P15 | 비교집단 설정과 차별의 합리성 심사: 차등취급의 합리성 또는 평등 위반이 쟁점일 때 | 비교집단 특정 → 관련 공통점·차이 확인 → 차등취급 특정 → 정당화 사유 심사 → 평등 위반 여부 |
| P16 | 구체적 작위의무와 권한 불행사 심사: 권한 보유에서 구체적인 행사의무 및 불행사 책임으로 나아갈 때 | 권한·직무 및 보호법익 확인 → 구체적 위험·예견·회피 가능성 검토 → 작위의무의 유무 확정 → 불행사의 위법·책임 심사 |
| P14 | 선례의 재검토와 변경: 실제 판례의 선례 변경 과정과 적용 범위를 설명할 때 | 종전 선례 확인 → 변경 판례의 판단 근거 → 변경 내용과 범위 확인 → 사안 적용 |
| O01 | 선결문제 우선 판단: 소송요건이나 심판 범위가 본안 판단의 전제가 될 때 | 소송요건·심판대상 확인 → 본안 판단 가능 범위 확정 → 본안 심사 |
| O02 | 원심 이유와 결론의 분리 심사: 원심 이유의 오류와 결과 유지 여부를 나누어 심사할 때 | 원심 논거 확인 → 법리상 오류 교정 → 다른 근거로 결론 유지 여부 판단 → 상고 처리 |
| O03 | 결론에 충분한 사유 확정 후 판단 종료: 결정적 사유로 결론이 정해져 일부 보조 쟁점의 판단을 생략할 때 | 결론을 결정하는 사유 인정 → 나머지 쟁점의 결과 영향 확인 → 판단을 생략하는 이유 명시 |

요건·증명 상태·권한·규정의 효과 방향·시점을 해당 판례에서 확인한다. 선례 변경이나 유추에 관한 서술은 실제 판례가 채택한 판단 범위와 연결한다.
