# MEKA 곽윤직

**Morphology-Enhanced Korean Argumentation**

한국 법률 실무의 관습적인 어휘, 문장 구성과 논리 전개를 재현하는 AI 글쓰기 스킬입니다. AI가 구조를 구상하고 작성·퇴고하며, Python 스크립트가 형태소 기반 문체 측정과 최종 문서 대조를 맡습니다.

## 계기

AI가 작성하는 법률문서는 미묘하게 실제 법조인이 작성하는 글과 느낌이 다르게 느껴집니다. 사실 실제 법조인들도 그 이유를 설명하기는 정말 어렵습니다. 왜냐하면 애초에 법조문부터 실생활에서 쓰는 언어와 다르기 때문이죠.

쉬운 법률용어를 정착시키려고 노력을 하고 있지만, 애초에 이미 실생활과 법조문이 시간을 거치며 멀어져있고 그 문장 자체도 법의 일부처럼 되어버려 바꾸기 어려운 문제가 있습니다.

더불어 대부분의 법조인들은 사법연수원 등과 같은 공통적인 교육기관을 거치고 선배들도 같은 교육과정을 거치며 어느정도의 공통적인 글쓰기 관습을 체득합니다.

AI의 한국법 능력은 2026년 현재 그다지 나쁘지않지만 여전히 어색한 이유는 특유의 주장에 대한 균형을 맞추려는 편향에 대한 안전장치, 마치 논리를 설명하듯 설교하는 논리 전개방식, 더불어 영어권 특유의 묘사방식과 비유, 수동태나 나열방식 등에서 나타나는 번역체는 특히나 한국법률과 관련된 문서를 작성할때 약점을 드러내게 만듭니다.

이에 여러 연구에서의 아이디어와
실제 판례에서의 형태소 데이터, 논리 전개방식의 추상화를 통해

한국 고유의 법적사고력, Legalmind를 적어도 표현방법에서는 구현하려 해당 스킬을 작성하였습니다.

더불어 제 첫 법학의 입문을 안내한 민법총칙의 저자이신 곽윤직 교수님을 법학적 사고방식의 정수라고 생각하여, 존경을 담아 해당 스킬의 이름에 참고하였습니다. 

제 서재 한켠을 차지하는 민법강의 시리즈는 낡아도 여전히 가치있고, AI시대에서 오히려 모방할 수 없는 동시에 지향해야 할 지점이라고 생각합니다.




## 작성 흐름

1. 쟁점에 맞는 논리 전개 구조를 구상합니다.
2. 구조에 따라 내용을 작성하고 의미 단위로 문단을 나눕니다.
3. 법리의 근거 판례 원문과 적용 범위를 확인합니다. 근거 확보가 필요한 논리는 검색·확인 후 다시 작성합니다.
4. 문체를 측정하고 실무 예문을 참고해 퇴고한 뒤 재측정합니다.
5. 서식·첨부·본문을 대조하고 최종 페이지를 확인하여 사용자에게 제출 결정을 요청합니다.

문체 수치는 참고 집단의 분포 안에서 현재 글의 위치를 보여줍니다. AI는 문맥과 의미 보존을 함께 판단하여 수정하거나 유지할 부분을 선택합니다.

## 설치

Claude Code의 개인 스킬 폴더에 설치합니다.

```sh
git clone https://github.com/EESIZ/meka_gwak.git ~/.claude/skills/meka-gwak
```

프로젝트에서만 사용할 때는 대상 프로젝트의 `.claude/skills/meka-gwak`에 복제합니다. Codex에서는 `~/.codex/skills/meka-gwak`을 사용합니다.

Python 3.10 이상이 필요합니다. 사용자 작업 폴더에 가상환경을 만들고 설치된 스킬의 `requirements.txt`로 의존성을 설치합니다. 운영체제별 실행 경로와 명령은 [실행 방법](references/runtime.md)에 있습니다.

Claude Code에서는 `/meka-gwak`과 함께 사건 자료, 문서 종류, 제출처와 확보한 판례를 전달합니다. Codex에서는 `$meka-gwak`을 지정합니다.

## 적용 범위

민사·행정 판결문은 같은 분야·문서 종류의 수치 분포를 참고합니다. 형사와 그 밖의 문서 종류는 예문 또는 사용자가 제공한 실무 자료를 중심으로 검토합니다.

스크립트는 문체 측정과 기계적 대조를 담당합니다. 판례 검색·법리 검토, 의미 보존 확인과 최종 페이지 검토는 AI 및 사용자가 수행합니다. 문체 재현 효과는 별도 사건과 일반 AI 대조군을 이용한 실험으로 평가할 대상입니다.

## 테스트

의존성을 설치한 Python으로 저장소 루트에서 실행합니다.

```sh
python -m unittest discover -s tests -v
```

배포 준비 과정에서 Windows / Python 3.12 환경의 56개 테스트와 실제 DOCX·PDF 대조를 확인했습니다. 이 결과는 도구 동작의 검증이며, 법률적 정확성이나 문체 재현 효과의 통계적 입증은 별도 평가 범위입니다.
